HARDENED FOUNDATIONS

Zero-Trust Sovereign Architecture

Strict separation between control plane coordination and local hardware compute.

ChaCha20-Poly1305 Relay

End-to-end encrypted relay sockets derive directional keys via Ephemeral Diffie-Hellman with monotonically tracked nonces and replay cache protection.

Zero Cloud Storage

Personal files, audio recordings, documents, and vector embeddings remain 100% on edge nodes. The cloud control plane coordinates identity and socket handshakes only.

Token Family Rotation

Strict refresh token rotation automatically invalidates entire token families upon reuse detection, cutting off compromised replay attacks instantly.

Hardware Keystore Isolation

Credentials and private keys are safeguarded using Windows DPAPI, macOS Secure Enclave / Keychain, and Android Hardware Keystore with biometric gates.
