Zero-Trust Architecture

Engineered for defense-in-depth with hardened boundaries between control plane and edge nodes.

ChaCha20-Poly1305 Relay

Handshakes derive distinct ephemeral directional keys with monotonically tracked nonces and replay cache protection.

No Personal Data Cloud Storage

Files, audio transcripts, and embeddings stay strictly local to your registered hardware nodes. Control plane holds metadata only.

Token Family Rotation

Automatic detection and invalidation of compromised refresh token chains with immediate session group revocation.
